# GNRUselessDelusion64

**What if _Use Your Illusion I & II_ had been issued as a Commodore 64 cartridge library in 1991?**

A fan-made alternate-history microsite presenting the two 1991 albums as a chunky C64 cartridge music archive. The interface tracks known 8-bit/chiptune interpretations and distinguishes general CHIP arrangements from C64/SID material.

## Run

Static site. Open `index.html` or serve the directory with any HTTP server.

## Visual source

The visual direction is inspired by AVG's **Guns N' Roses — Use Your Illusion 2** ANSI artwork from the Blocktronics **B-Sides** artpack:
